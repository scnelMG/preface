# 공개용 사본의 범위

> 작성일: 2026-11-18

이 저장소는 Preface 팀 프로젝트를 개인 포트폴리오로 소개하기 위한 소스 사본이다. 원본 운영 환경을 이전하거나 기존 서비스를 재배포하는 작업은 아니다.

## 기준

- 원본: SSAFY 15기 B204 Preface 팀 프로젝트
- 기준 브랜치: 원본 GitLab `main`
- 기준 커밋: `378a2a2f37d38df49d3335990c2ad3caceeb94ff`
- 이력: 해당 커밋의 소스 스냅샷으로 새 이력을 시작한다. 이전 커밋·브랜치·태그·MR·Jira는 옮기지 않는다.
- 기여 표기: 팀과 개인 기여를 구분한다. 원본의 작성자를 개인 작성자로 바꾸지 않는다.

## 포함·제외

프론트엔드, 백엔드, 작업 관리자, GPU 파이프라인, 공통 편집 엔진, 서비스 간 계약, 테스트·평가 도구, 합성 샘플, 로컬 의존 서비스 구성을 포함한다.

| 항목 | 처리 |
| --- | --- |
| 과거 Git 기록 | 가져오지 않는다. 과거에 삭제한 정보가 공개 이력으로 따라오는 것을 피한다 |
| 개인 얼굴·촬영 영상·개인화 모델 | 공개 대상에 포함하지 않는다. 발표 ZIP도 업로드하지 않는다 |
| 운영 접속 안내·서버 설정·팀 내부 절차 | `exec`, 운영용 `infra`, GitLab 설정·운영 스크립트, 내부 가이드·계획·기획 사본 등을 제외한다 |
| 기존 운영 호스트·문의 메일 | 예시 도메인·주소로 치환한다 |
| 분석 도구 | GA4·Clarity 프로젝트 ID를 비워 원본 통계로 전송하지 않게 한다 |
| 홍보용 MetaHuman·랜딩 영상 | 소스에 홍보물 전용 예외로 기재되어 있어 재배포 범위를 확인하기 전까지 자산을 제외한다 |
| 기본 얼굴 모델 | 합성 샘플 manifest·원본 GNM 라이선스를 보존한다 |
| README 성과 | 발표자료에 제시한 팀 성과로 명시한다. 운영 사례와 통제 부하 테스트를 구분한다 |

랜딩 연출 코드는 남아 있지만 일부 자산은 빠져 있다. 공개본의 랜딩은 원본과 같게 표시되지 않을 수 있다. 합성 모델을 사용하는 `/lab`을 로컬 확인의 시작점으로 삼는다. AI 상담·OAuth·스토리지·GPU 복원은 별도 구성이 필요하다.

원본 영역별 README와 기술 문서에는 제외한 내부 문서를 가리키는 링크가 남을 수 있다. 공개본의 실행 안내는 [개발 안내](development.md)를 기준으로 한다.

## 검증 범위

원본 소스 스냅샷과 공개용 소스에서 Gitleaks 검사를 수행한다. 추가로 운영 호스트·실제 분석 ID·개인 환경 파일·비공개 대상 경로의 포함 여부와 README 링크를 확인한다. 비밀정보 자동 탐지는 자산의 저작권 검토나 모든 문자열의 수작업 검토를 대체하지 않는다.

전체 운영 서비스·실제 사용자 데이터·GPU 하드웨어를 이용한 재현 시험은 수행하지 않는다. 프로젝트 전체의 재배포 라이선스를 새로 정하지 않으며 기존 외부 자산의 라이선스를 보존한다.

이번 공개본 준비에서 수행한 검증은 다음과 같다.

| 검증 | 결과 |
| --- | --- |
| Gitleaks `dir` 검사, 비밀 값 마스킹 | 원본 스냅샷·공개본 모두 탐지 0건 |
| 공개 범위 자체 검사 | 제외 경로·환경 파일·운영 호스트·분석 ID·외부 IP·README 링크 확인 통과 |
| 공개본의 웹 회귀 검사 | 아래 7개 파일, 69개 테스트 통과 |
| 전체 빌드·백엔드 통합·GPU 재현 시험 | 미실행: 공개본의 설정 익명화·문서 변경에 집중했으며 별도 환경이 필요한 전체 서비스는 실행하지 않았다 |

웹 테스트는 `apps/web`에서 다음 명령으로 실행했다.

```powershell
& .\node_modules\.bin\vitest.cmd run src/shared/analytics/Analytics.test.tsx src/features/account/mattermostAvailability.test.ts src/features/legal/legal.test.tsx src/features/layout/SiteFooter.test.tsx src/features/face-reading/flag.test.ts src/features/admin/environment.test.ts src/features/admin/AdminGate.test.ts
```
