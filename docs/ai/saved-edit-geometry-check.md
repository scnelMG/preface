# 저장 시안 눈·코 형상 사전 점검

AI-102의 실제 모델 검수 전에 원본 `head.glb`, 같은 생성 작업의 `rig.json`, API-EDIT-03 시안 응답 `data`를 보안 작업 디렉터리에 둔다. 얼굴 자산·응답 JSON은 저장소에 넣지 않는다.

```sh
node services/gpu-worker/reconstruction/tools/check_saved_edit_parts.mjs \
  <보안-모델-디렉터리> <보안-시안-응답.json>
```

눈 상태가 있으면 GLB·리그·눈 판정 해시 및 schema·엔진·리그·위상 버전을 시안의 승인값과 대조하고, 저장된 눈 값을 승인 범위 및 눈 엔진의 형상 안전 검사에 넣는다. 눈 편집 요청이 있으면 실제 피부 정점 변위도 확인한다. 코 상태가 있으면 기존 `checkNoseEdit`로 원본 GLB 최종 피부의 코 변형을 검사한다. 출력은 통과 여부만 포함하고 모델 식별자·해시·얼굴 자산을 출력하지 않는다. 실패하면 종료 코드 1과 일반 오류 문구만 낸다.

`componentChecksPass: true`는 **눈과 코를 각각 검사한 결과**다. 눈 상태가 기본값이어도 통과할 수 있으므로 요청 방향·변화량이 실제 화면과 맞는지는 이 도구로 판정하지 않는다. `eyeBindingVerified`는 눈 승인값과 자산·버전을 대조했는지만 표시하며 코만 검사한 경우에는 `false`다. `eyeSkinScope: "largest-eye-region-skin"`은 눈 주변 정점이 가장 많은 **피부 메시 하나만** 검사했다는 뜻이다. 화면에 그리는 다른 피부 메시의 변형은 이 결과에 포함되지 않는다. `jointMeshChecked: false`가 항상 함께 나오며, 눈+코를 합친 최종 메시의 자기교차·안구 관통·비대상 이동이나 네 방향 외관을 합격으로 판정하지 않는다. 실제 생성 모델의 저장값·원본 모델·리그를 같은 보안 환경에서 대조하고, 합성 최종 메시 검사와 외관 기록을 추가해야 AI-102 완료를 판단할 수 있다.

AI-509부터 신규 눈 편집, 눈 변형을 보존하는 코 편집, 눈 상태가 있는 이력 복원은 [사설 편집 검사기](../../services/gpu-worker/reconstruction/edit-validator/README.md)의 저장 검사를 거친다. 위 사전 점검 도구는 서버의 자기교차 검사와 별도로 사용한다.

AI-647은 실제 생성 모델의 세 쌍꺼풀 모양에서 접힘 단면이 피부를 관통하는 사례를 재현했다. 눈 엔진은 설계선의 높이와 모양을 유지하면서 더 얕은 단면을 적용한다. 저장된 눈 편집값은 유지되며 기존 시안도 새 엔진으로 다시 그린다. 개발 배포 검수에서는 네 방향 외관과 저장·재조회·되돌리기를 별도로 확인한다.

AI-648은 생성 피부에서 기본 높이의 접힘이 자기교차를 만드는 사례를 추가로 수정했다. 단면 폭과 모양별 설계선은 유지하고 피부에 더하는 접힘 변위만 절반으로 줄인다. 기존 눈 편집값과 저장 검사 기준은 그대로 사용한다. 개발 자산의 읽기 전용 검사에서 한 모델의 세 모양과 높이 20·25·30·40 표본 12건, 기본 높이에서 코 조절을 더한 3건, 두 모델의 저장 이력 19건이 통과했다. 각 모델의 전체 조절 범위와 실제 화면 외관은 이 표본 결과에 포함하지 않는다.

AI-682는 쌍꺼풀의 원래 접힘 깊이와 변위를 복원한다. 브라우저와 저장 검사기가 공유하는 엔진은 새로 교차한 삼각형과 주변 정점부터 변위를 줄인다. 국소 제한으로 해결하지 못하면 기존 형상 제한 방식으로 접힘을 축소하고, 저장 검사는 접힘과 트임을 합친 형상을 다시 검사한다. 같은 저장값을 열어도 접힘을 더 뚜렷하게 다시 그린다.

생성 시안에서 코를 직접 조절할 때 브라우저의 코 리그와 최종 피부 검사를 통과한 값만 화면에 반영한다. 코 슬라이더와 저장된 코 제어점 변위를 합한 피부를 검사한다. 새 자기교차, 면 붕괴, 보호 정점 이동을 찾으면 마지막으로 표시한 값과 3D를 유지한다. 앞선 저장 응답과 합친 미리보기 조합이 검사에 실패하면 코는 서버가 확정한 값으로 복구한다. 서버는 최종 저장 전에 원본과 리그 결속을 확인하고 실제 저장값을 검사한다.

AI-741의 코 엔진 `0.13.0`은 콧대 높이의 변위를 중앙과 옆면에 분산하고 코뿌리와 코끝 방향으로 완만하게 줄인다. 미리보기와 저장 검사기는 리그에 기록된 같은 버전을 적용한다. 기존 `0.12.0` 리그는 저장된 시안의 형상을 재현하며, 새 변형을 사용하려면 새 리그를 생성하고 해당 리그의 범위를 승인해야 한다. 변형이 달라져도 눈·입술 보호와 최종 메시 검사를 적용한다.

체중 변형만 보완한 기존 모델에 윤곽을 추가할 때는 새 GLB가 원본 피부와 기존 타깃을 그대로 유지하는지 확인한다. 추가한 윤곽의 양 끝값을 서버 형상 검사에 통과시키고 코·눈·체중 승인을 새 GLB에 결속한다. 교체 후에도 원본과 직전 체중 GLB의 키를 추적하며 기존 편집 이력은 같은 시안에 둔다.
복구 후보의 새 윤곽 타깃은 모두 눈·코 보호 영역에서 변위가 0이고 바깥쪽에서 원래 세기로 부드럽게 이어진다. 최초 생성 시의 윤곽 레시피는 그대로 사용한다.
