# 체중 변화 얼굴형 시뮬레이션 사전 검증

- Jira: S15P31B204-501
- 검증일: 2026-11-02
- 입력: 저장소의 수식 기반 `createSyntheticHead()` 합성 머리 1종. 실제 얼굴 사진·영상·생성 GLB는 사용하지 않았다.
- 실행: `cd apps/web && node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/weight-poc.mjs`

## 결과

합성 메시의 볼·턱선·목에 같은 방향의 연속 변형을 주고, −1·0·+1 상태를 비교했다. 0은 원본 정점 배열과 정확히 일치해 원복 가능했다. 그림은 정면·측면 투영 윤곽의 중첩이다. 파란색이 원본이고 회색은 축소, 분홍색은 확대다.

## 판단과 한계

**합성 모델에서 방향별 미리보기와 원복은 가능하다. 실제 서비스의 체중 변화 기능은 아직 열지 않는다.** 현재 서비스의 코 리그는 볼·턱선·목을 움직이는 계약이 아니다. 이 PoC는 합성 머리의 정점에만 변형을 계산했고 GLB, 서버 저장, 모델별 승인 범위, 사용자 화면에는 연결하지 않았다.

형상 검사는 삼각형 뒤집힘만 확인했다. 자기교차, 얼굴과 목의 경계, 피부 질감, 머리카락, 정면·측면의 자연스러움은 판정하지 않았다. 합성 목은 열린 원통이고 실제 얼굴의 해부학적 구조와 다르다. 다음 구현 전에 권한 있는 모델의 볼·턱선·목 리그 또는 안전한 변형 마스크와 형상 검사를 마련하고, 외관을 별도로 검수해야 한다. 입력은 방향·정도만 허용하고 실제 체중 수치로 외모나 건강 상태를 예측한다고 표현하지 않는다.
