# AI 실장님의 얼굴 비율 분석 (S15P31B204-822)

생성 시안의 상담에서 `내 얼굴 비율 분석`을 누르면 눈·코, 입술, 인중·턱, 옆모습의 비율을 볼 수 있다. 상세 버튼을 누르거나 `입술은요?`처럼 이어 물으면 해당 부위의 측정 방식도 보여 준다. 얼굴과 편집 이력은 그대로 유지된다.

브라우저는 현재 시안에 적용된 3D의 피부 정점에서 비율을 다시 계산한다. 원본 GLB는 기준점 인덱스와 비교 기준을 제공한다. 슬라이더와 상담 편집, 되돌리기, 새로고침은 저장된 시안이 뷰어에 반영된 뒤 측정한다. 비교 미리보기와 실시간 표정은 측정에서 제외한다. 생성 자산의 표준 축과 468개 기준점 매핑을 사용한다. 정밀 메시에서는 가장 가까운 원본 정점으로 매핑된 주변 정점 대신 실제 정밀 정점 인덱스를 사용한다. 아래 번호는 프로젝트의 기준점 배열 인덱스다. [3D Facial Norms](https://pubmed.ncbi.nlm.nih.gov/26492185/)와 [FaceBase 기준점 정의](https://www.facebase.org/resources/human/facial_norms/notes/)를 측정 용어의 근거로 참고하되, 프로젝트의 자동 기준점과 동일한 정확도로 검수됐다고 가정하지 않는다.

| --- | --- |

빠지거나 서로 맞지 않는 기준점이 있으면 영향을 받는 수치만 표시하지 않는다. 검수 오차와 절대 크기 보정이 없는 자동 측정은 3D 시안 안의 참고 비율로 표시한다. 촬영 표정이나 원본 재구성 오차는 입술·턱 등의 기준점 위치에 영향을 줄 수 있다. 전체 분석과 눈·코 상세에서는 로그인한 소유자의 기존 원본 검수 API를 조회해 콧볼·눈 안쪽 비율의 범위를 함께 표시한다. 자동 좌표가 없는 시안에서도 해당 검수 기록을 확인할 수 있다. 자동 비율의 현재값과 원본값이 다르면 분석 답변에 차이를 표시한다. 원본 검수 기록과 사진 대조에는 원본 데이터를 사용한다.

콧볼과 눈 안쪽 간격을 함께 묻는 질문은 서버가 로그인한 소유자의 원본 검수 기록으로 계산한다. 원본 검수 결과는 모델·리그 버전이 바뀌면 사용할 수 없다.

| 질문 | 자료와 계산 | 결과 제한 |

| 입술 비율·트렌디 볼륨·클래식 황금비율 | [Heidekrueger 등](https://pubmed.ncbi.nlm.nih.gov/28318919/)은 한 여성 모델의 변형 이미지를 사용한 다국가 설문(35개국·1,011명 응답)에서 윗입술:아랫입술 1:1 선호를, [Frank 등](https://pubmed.ncbi.nlm.nih.gov/35666164/)은 변형 이미지 평가(59명)에서 1:1.6의 가장 높은 평가를 보고했다. | 조건이 다른 연구의 선호 사례로만 설명한다. 세로 높이 비율과 전체 볼륨을 구분한다. 개인의 분류·점수·시술 방향에는 쓰지 않는다. |
| 얼굴 전체의 황금비율 | [Naini의 근거 검토](https://pubmed.ncbi.nlm.nih.gov/38228978/)는 수학적 황금비를 얼굴 미나 수술 목표와 연결할 설득력 있는 근거가 없다고 정리했다. | 보편적인 목표값을 제시하지 않는다. |

개인 수치와 출처를 GMS가 생성하지 않는다. 분석 질문의 종류에 따라 앱이 검수값 또는 현재 시안의 정점을 사용하며, 연구 질문에는 확인한 출처를 보여 준다. 기존 GMS 일반 상담은 유지한다. 비교 서비스 캡처의 수치를 학습 데이터, 개인 판정 기준, 검수 기록으로 사용하지 않는다. 자동 측정의 실제 얼굴 오차는 별도의 기준 데이터 검증이 필요하다.

고민 상담과 얼굴 분석에 이어지는 자연어 질문은 GMS가 전체·눈코·입술·인중턱·옆모습의 고정 부위 ID로 좁힌다. 상담 중인 부위가 있으면 해당 ID만 참고로 보낸다. 부위 의도 분류에는 정점, 개인 수치, 원본 사진과 파일 주소를 전송하지 않는다. 앱은 검증된 부위 ID를 받으면 상대 비율을 AI 실장님 답변에 붙인다. 현재 답변의 ‘측정 근거 보기’에서 기준점, 검수 기록, 출처와 사진 대조를 펼칠 수 있다. 다른 부위를 고르면 질문과 답변이 대화에 추가된다. 3D 비교는 별도의 상담 선택을 통해 진행한다.

분석 답변은 현재 편집 3D에서 확인한 특징을 먼저 설명하고, 수치·측정법·출처는 같은 답변의 근거 보기에 둔다. 전체·인중턱·옆모습 분석에서 해당 부위와 열린 조절이 근거에 연결되면 AI-886의 후보 조회와 GMS 정렬을 재사용한다. 분석 부위와 선택된 후보는 같은 상담 답변에 저장한다. 기준점이나 관련 조절이 부족하면 확인한 결과만 보여 준다. 각 제안에서 같은 각도 비교를 열거나 직접 조절로 이동할 수 있다. 선택지는 시안 버전에 묶이며, 후속 3D 비교를 적용하기 전에는 얼굴과 편집 이력을 바꾸지 않는다.

`어디부터 바꿔보면 좋을까요?`를 누르면 현재 시안의 기준점과 열린 조절을 대조해 최대 세 가지를 제안한다. 앞트임은 현재 시안의 눈 안쪽 간격과 바깥쪽 너비, 코끝 앞뒤는 옆모습 기준선, 윤곽은 아래턱 너비나 턱끝 측정과 연결한다. 정면이나 옆모습 또는 유지할 부위를 지정하면 후보에 반영한다.

다음 조절을 물으면 브라우저가 현재 시안에서 각 슬라이더의 열린 방향을 한 단계씩 내부 계산한다. 코끝 앞뒤는 기존 형상 검사를 통과한 경우만 측정한다. 턱끝과 사각턱은 현재 시안의 GLB 변형으로 측정한다. 앞트임은 현재 쌍꺼풀과 다른 눈 조절값을 유지한 상태에서 눈 워커로 시험한다. 워커가 변위를 제한하거나 기준점에서 전후 차이를 확인할 수 없으면 해당 방향은 제외한다. 이 과정에서 화면 메시를 갱신하거나 편집을 저장하지 않는다. 3D를 불러오는 동안 보낸 추천 질문은 준비되면 이어서 처리한다.

API는 시안의 지원 범위를 재확인하고 부위별 참고 자료를 조회한다. 전후 비율이 다른 후보만 질문, 측정값, 관련 자료와 함께 GMS에 전달한다. 전체 추천에는 근거가 충분한 서로 다른 후보를 두세 개 고르도록 요청한다. GMS는 첫 문장에서 현재 계측값이 드러내는 모습과 후보를 고른 이유를 설명한다. 둘째 문장은 조절 방향과 시험에서 확인된 변화를 연결한다. 서버는 전후값에서 읽은 폭·길이·거리의 변화를 함께 전달한다. 서버는 후보·측정·출처·방향과 답변 속 조절 표현이 실제로 전달한 시험 결과와 일치하는지 확인한다. 사용자가 전체 추천을 명시하면 앞서 선택한 슬라이더가 있어도 전체 후보를 검토한다. 전후 수치와 출처는 계산값과 등록된 자료를 표시한다. 근거가 부족하거나 GMS가 응답하지 않으면 추천을 보류한다. GMS에는 사진, 메시, 정점 좌표, 파일 주소를 보내지 않는다.

제안을 펼치면 상담 설명과 슬라이더 이동을 제공한다. 자세한 전후 측정값과 방법, 해석 범위는 근거 보기에서 확인한다. [Ricketts의 옆모습 기준선 연구](https://pubmed.ncbi.nlm.nih.gov/5238879/)와 [FaceBase 기준점 정의](https://www.facebase.org/resources/human/facial_norms/notes/)는 측정 기준을 뒷받침한다. 전후 차이는 해당 3D 시안에서 재현한 효과다. 상담 답변이 렌더링하는 시험값과 설명은 그 답변의 기록을 따른다. 직접 조절을 열 때는 현재 시안에서 조절할 수 있는지 다시 확인한다.

비율 분석의 기존 비교는 분석 주제에 맞는 선택지로 이어진다. 비교 카드는 해당 제안 아래에서 열리고, `시안에 적용`을 눌러야 저장된다. `직접 조절하기`는 열린 비교를 닫고 해당 슬라이더로 이동한다.

슬라이더를 선택한 상태에서도 ‘손봐볼 만한 곳을 추천해 주세요’처럼 열린 후보를 묻는 표현은 전체 추천으로 처리한다. 펼친 카드의 설명은 현재 시안에서 관찰한 폭·길이·위치로 시작하고, 조절 방향과 시험에서 확인한 변화를 제안으로 이어서 말한다.

추천 근거 조회는 조절 항목과 측정 지표를 기준으로 검토된 카드를 찾는다. 카드마다 문헌이 뒷받침하는 정의와 이 시안의 해석 한계를 구분해 전달한다. 정면 자료는 표면 기준점을 정의하며, 사각턱에 쓰는 앱의 표면 폭을 뼈의 턱각으로 해석할 수 없다는 한계도 알려 준다. 옆모습 자료는 입술의 상대 위치를 설명하는 선의 근거이며, 선 길이로 정규화한 비율의 변화는 입술의 실제 이동을 의미하지 않는다. 현재 시안에서 무엇이 보이고 어느 조절이 어떻게 달라지는지는 실제 전후 시험값을 사용한다. GMS는 추천 이유, 방향, 보이는 차이를 쉬운 존댓말 두 문장으로 작성한다. 숫자나 ‘오분의 사’처럼 풀어 쓴 비율은 본문에서 걸러내고, 전후 수치와 측정법은 근거 보기에서 제공한다.

전체 추천에서는 질문과 관련 있고 시안에서 검증한 후보 중 눈·코·윤곽별로 하나씩 선택한다. 같은 부위가 중복되면 먼저 선택한 후보만 남긴다. 유지하거나 제외해 달라고 한 부위, 잠긴 조절, 근거가 부족한 항목은 추천에서 제외한다.

GMS가 고른 후보가 두 개 미만이거나 GMS 호출이 실패하면, 전후 차이를 확인한 다른 부위를 순서대로 추가해 최대 두 개를 채운다. 보완 후보의 설명은 해당 시험의 조절 방향과 전후 계측값을 사용한다. 시안, 편집 버전, 질문, 계측 후보와 GMS 설정이 같으면 검증을 통과한 GMS 응답을 새 대화에서도 최대 7일간 재사용한다.
