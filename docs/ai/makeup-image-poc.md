# 합성 얼굴 메이크업 이미지 적용 사전 검증

- Jira: S15P31B204-503
- 검증일: 2026-11-02
- 자료: 내장 이미지 생성 도구로 만든 가상 성인 CGI 얼굴 1장. 실제 인물 사진·회원 모델·기존 3D 원본은 사용하거나 변경하지 않았다.
- 방법: 같은 원본에 자연스러운 화장과 강한 화장을 각각 독립적으로 편집 요청했다. 아래 이미지는 검토용 WebP 사본이며 시간·화소 비교는 생성 원본 PNG로 기록했다.

## 관찰

- 자연스러운 화장: 브라운 눈화장, 연한 볼 색, 장밋빛 입술이 보인다. 정면 육안으로는 같은 얼굴·자세로 보이고 눈·입술 주변에 뚜렷한 색 번짐은 보이지 않는다.
- 강한 화장: 스모키 눈화장과 빨간 입술이 보인다. 입술 색 경계가 원본 입술 윤곽보다 두껍게 보여 형태가 달라 보일 수 있다. 효과를 피부색만 바꾸는 엄격한 마스크 적용으로 간주할 수 없다.
- **실패·한계 사례:** 편집 대상이 아닌 코 중앙 120×130px 영역도 원본과 자연스러운 화장 이미지 사이에서 변했다. 원본 PNG 기준 FFmpeg `psnr` 평균은 **35.08 dB**다. 즉 편집 도구가 이미지 전체를 다시 만들며, 요청한 화장 영역 밖 화소의 보존은 확인되지 않았다. 이 수치는 얼굴 동일성 점수가 아니다.
- 처리 시간: 도구 호출의 관찰 경과 시간은 원본 생성 **21.6초**, 자연스러운 화장 **27.3초**, 강한 화장 **24.1초**였다. 네트워크·도구 실행 시간을 포함한 단일 호출 관찰값이며 p95나 서비스 서버 지연이 아니다.
- 비용: 내장 도구는 호출별 과금액·토큰 수를 제공하지 않았다. 제품에서 쓸 공급자와 단가도 확정되지 않아 **원가/시안은 산출 불가**다. 무료라고 판단하지 않는다.

## 결정

**현재 서비스 도입은 보류한다.** 한 합성 얼굴의 육안 결과만으로 실제 얼굴의 동일성·눈과 입술 경계·피부색 일관성을 보장할 수 없다. 편집 영역 밖 화소 변화와 호출별 비용 불명확성도 남았다. 다음 시험은 권한 있는 합성 자료 여러 장, 국소 마스크/원본 보존 비교, 공급자 단가와 반복 호출 p50/p95 측정을 먼저 갖춘 뒤 진행한다. 현재 3D 원본이나 얼굴 수정 기능에는 연결하지 않는다.

## 재현 기록

내장 `image_gen`의 생성 모드로 정면·무화장·회색 배경의 비식별 CGI 얼굴을 만들었다. 같은 원본을 참조한 `identity-preserve` 편집 모드로 ① 브라운 눈화장·연한 볼 색·장밋빛 입술, ② 스모키 눈화장·빨간 입술을 요청했다. 두 편집 모두 얼굴 구조·자세·조명·배경 유지, 화장 영역 밖 변경 금지를 명시했다. 생성 파일을 FFmpeg `libwebp` 품질 92로 검토용 사본으로 변환했다. 코 영역 비교는 원본 PNG 두 장에 `crop=120:130:510:600` 후 `psnr`를 적용했다.
