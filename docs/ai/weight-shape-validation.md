# 생성 얼굴의 체중 방향 얼굴형 변형 검증 (S15P31B204-583)

> 최종 갱신: 2026-11-05 · 상태: 새 생성 모델·기본 체험 연결 완료, 개발 기존 생성 모델 22개 활성화 완료

이 기능은 몸무게나 건강 상태를 추정하지 않는다. 볼·턱선·목의 **얼굴형 볼륨 방향**을 원본과 비교할 수 있는 3D 변형만 다룬다. [AI-501 사전 검증](weight-change-poc.md)은 합성 머리에서 가능성을 보였으며 실제 생성 얼굴의 안전 범위를 입증하지 않았다.

## 모델 산출물

GPU 워커는 기존 윤곽 모프를 굽는 단계에서 `contour.weight_shape_neg`와 `contour.weight_shape_pos`를 선택적으로 추가한다. 기존 볼살·턱 근육 변위에 목의 완만한 방사형 변위를 합친다. 목 위아래 경계와 눈·코·입술·귀 보호 영역은 움직이지 않도록 거리를 두고 감쇠한다. 원본 정점과 텍스처는 바꾸지 않으며 0은 원본이다.

GLB의 `asset.extras.live-mirror.weight_shape`에는 산출물 버전, 원본 fit 해시, 양방향 검사 통과 범위를 기록한다. 검사한 모델 형식·위상·fit 해시와 눈·입술 보호 영역이 없거나 어느 한 방향도 통과하지 않으면 **타깃 쌍을 넣지 않는다**. 기존 모델에는 자동 소급 적용하지 않는다. GLB를 교체하면 기존 코·눈 승인 해시가 달라지므로 별도 재승인이 필요하다.

AI-586은 공개 합성 남녀 기본 모델에만 보호 영역을 템플릿 좌표에서 정해 같은 검사를 적용했다. 두 GLB 모두 기존 윤곽 타깃과 원본 형상·텍스처를 유지하고 얼굴형 타깃 쌍을 추가했다. 기본 모델은 브라우저 체험용이며 저장 시안은 만들지 않는다. 기존 사용자 생성 모델에는 이 경로를 적용하지 않는다.

AI-608은 홈 첫 화면의 남녀 기본 모델 조절 카드에도 기존 체험 실험실의 윤곽·체중 변화 슬라이더를 연결한다. GLB가 보고한 지원 타깃만 열고, 다른 편집과 체중 변화의 동시 상태는 기존 단독 형상 검증 범위 밖이므로 계속 잠근다. 체험값과 이력은 브라우저 안에서만 유지한다.

AI-587의 기존 생성 모델 소급 배치는 개발 서버의 비공개 S3에서 원본 GLB를 읽고, 새 타깃 쌍만 추가한다. 원본 BIN·접근자·기존 타깃·다른 메시·텍스처가 동일한지 확인하고, 모델 fit·버전 및 두 방향 형상 검사를 통과한 결과만 **다른 비공개 S3 키**로 올린다. 원본 키는 덮어쓰지 않는다. `infra/ec2/backfill-weight-shape-dev.sh`는 병합된 코드에서 개발 서버 `gitlab-runner`로 `--dry-run`을 먼저 실행한 뒤 `--apply`로 생성한다. 식별자·자산 키와 해시는 서버 안 권한 600의 `private-backfill/ai587/manifest.tsv`에만 남긴다. 이 단계에서는 `face_model`을 바꾸지 않았고, AI-588에서 새 자산에 승인 상태를 재결속해 전환했다.

개발 dry run에서 활성 기존 모델 22개 중 19개는 형상 검사를 통과했다. 나머지 3개는 과거 `mesh.glb`(시도 폴더 없음) 또는 `head.glb` 경로여서 키 형식 검사에서 빠졌다. 전자는 사용자·복원 작업 결속, 후자는 사용자·모델 ID 결속을 확인한 경우에만 허용한다. 결과는 비식별 건수로만 공유한다.

AI-587의 최종 개발 실행에서 22개 모두 형상 검사를 통과해 새 비공개 GLB와 manifest가 준비됐다. AI-588은 기존·신규 S3 객체의 해시와 원본 BIN·타깃·모델 결속을 다시 확인하고, 코 승인이 있던 모델은 새 GLB에서 검사기 검증을 잠금 밖에서 다시 실행한다. 눈 승인은 새 코 결속으로 DB 저장 거래 안에서 재승인한다. 코 승인이 없던 모델은 얼굴형만 새 GLB 키와 해시에 결속해 열고 기존 코·채팅 잠금은 유지한다. 모델 행을 다시 잠가 상태·기존 키·리그·승인 스냅샷을 확인한 뒤 새 키, 코·눈·얼굴형 승인, 원본 키를 한 거래로 저장한다. 시안과 편집 이력은 손대지 않는다. 삭제·탈퇴 때는 새 GLB와 원본 GLB를 함께 삭제 예약한다. 개발 배포 뒤 `infra/ec2/activate-weight-shape-dev.sh`를 `gitlab-runner`로 실행해 22건 모두 활성화했고 실패는 0건이었다. 코 승인 16건·눈 승인 5건이 유지되고, 새 자산과 승인 해시 불일치는 0건이었다. 시안 63건·편집 이력 598건은 전후 동일했다. 개발 화면에서 좁게·넓게·재조회·undo·redo·원본 복귀를 확인했다. 배치는 비공개 manifest만 읽고 집계 건수만 출력하며 재실행할 수 있다.

## 형상 검사

각 방향의 원본 대비 이동을 0.1·0.25·0.5·0.75·1 표본값에서 순서대로 확인한다. 보호 영역 이동, 새 삼각형 접힘·붕괴·과도한 늘어남, 새 자기교차가 생기는 첫 표본값 전에 멈춘다. 양쪽 모두 통과한 가장 큰 표본값만 GLB 모프 끝값으로 굽는다. 표본값 사이의 모든 조합을 증명한 검사는 아니다. 이 값은 **기술적 미리보기 범위**이며 실제 체중 변화량이나 의학적 한계가 아니다.

AI-583의 모프 굽기 검사는 각 모프를 단독 적용한 표본 지점의 기하 검사다. 눈·코·다른 윤곽 조절과 합친 연속 범위의 최종 형상과 실제 생성 모델의 피부 질감·목 경계 자연스러움은 아직 검증되지 않았다. AI-584는 승인된 모델의 단독 저장·재조회·undo를 연결하고 복합 저장을 차단했다. 화면에서는 서버 승인과 GLB 양방향 타깃을 함께 확인한다.

AI-614의 [복합 형상 표본 검사](weight-composite-validation.md)는 일부 기본 모델 조합에서 새 자기교차를 발견했고, 생성 모델 3종은 검사한 표본만 통과했다. 연속 범위와 시각 품질이 미확정이므로 복합 저장·화면 잠금은 유지한다.

AI-615는 공개 기본 모델의 입꼬리 부근 체중 모프를 조정해 AI-614의 실패 표본을 수정하고 독립 슬라이더 격자를 넓혔다. 같은 [복합 형상 검사 기록](weight-composite-validation.md)에 생성 모델의 복수 윤곽 조합을 원본 대비 최종 메시로 재검사한 결과를 남긴다. 최종 메시가 불합격인 조합과 연속 범위가 미검증인 조합은 계속 잠근다.

AI-603부터 체중 변화 미리보기 중 다른 코·윤곽 슬라이더를 움직이면 체중 값을 0으로 돌리고 새 값을 같은 저장 이력에 기록한다. 눈은 별도 저장 경로여서 체중 값 원복이 성공한 뒤 눈 조절을 연다. 명확한 채팅 편집도 저장 시 체중 원복과 새 효과를 한 이력으로 기록하며, 사용법 질문은 상태를 바꾸지 않는다. 다른 편집에서 체중 변화로 옮길 때 기존 편집을 임의로 지우지 않는다. 복합 상태의 서버 저장 차단은 그대로 적용한다.

## 문헌과 화면 표현 기준

- [Paton 외(2007)](https://pubmed.ncbi.nlm.nih.gov/17944682/)는 24명의 3D 얼굴 표면 스캔과 MRI를 비교했다. 체중 감소군 5명의 볼 표면 부피 변화 중앙값은 -1.5mL, 증가군 7명은 +3.1mL였다. 대상이 HIV 환자이고 표본이 작으므로 일반 사용자의 변화량으로 환산하지 않는다.
- [Sharma 외(2025)](https://pubmed.ncbi.nlm.nih.gov/40407186/)는 GLP-1 약물 사용자 20명의 전후 CT/MRI에서 중안면 전체 부피 감소 중앙값 9%를 보고했다. 집단의 지방층 변화이며 개인 얼굴 표면이나 이 서비스의 슬라이더 가중치와 일대일 대응하지 않는다.
- [대규모 체중 감소 후 3D 얼굴·목 측정(2020)](https://cris.maastrichtuniversity.nl/en/publications/morphological-changes-of-the-human-face-after-massive-weight-loss/)에서는 평균 목 부피 감소가 있었지만 전체 체중 감소량과 목 부피 감소량의 상관은 유의하지 않았다. 목 변형을 개인 체중값으로 보정하지 않는 근거다.
- [Ghafourzadeh 외(2020)](https://graphicsinterface.org/proceedings/gi2020/gi2020-3/)의 국소 3D 얼굴 모프와 부위별 부드러운 결합은 얼굴 부위 편집의 기법 근거다. 체중 변화의 개인별 정확도를 검증한 연구는 아니다.
- [FaceBase 3D Facial Norms](https://www.facebase.org/resources/human/facial_norms/notes/)에는 개인별 3D 메시와 촬영 시점의 체중 자료가 있지만, 개인 자료는 기관 윤리 승인과 데이터 접근 심사가 필요한 제한 자료다. 같은 사람의 체중 변화 전후를 추적한 데이터로 제시되지도 않아 현재 기능의 체중별 보정에 사용할 수 없다.

현재 볼·턱선·목 변위의 계수는 위 문헌에서 학습하거나 보정한 수치가 아니라 형상 검사로 제한한 **공학적 변형**이다. 문헌은 감량·증량 시 얼굴 부피가 달라질 수 있다는 방향 근거만 제공한다. 따라서 화면은 `감량 ↔ 원본 ↔ 증량` 방향의 미리보기로 안내한다. 공통 슬라이더의 수치는 미리보기 강도이며 실제 체중 변화율·체중 단위·건강 예측·개인별 변화량이 아니다. 실제 체중에 따른 얼굴을 예측하려면 같은 사람의 전후 3D 스캔과 각 시점의 체중, 사용 권한, 독립 검증이 먼저 필요하다.

## 검증 기록

합성 GNM 머리 2개(원본과 크기·위치가 다른 변형)에서 양방향 모프 굽기와 원본 불변을 검증했다. 보호 영역이 없거나 모델 버전이 다르면 잠그고, 검사기의 보호 영역 침범과 비유한 좌표 입력도 거절한다.

공개 합성 남녀 기본 GLB 각각의 양방향 끝값과 중간 표본 형상 검사가 통과했다. 기존 타깃의 접근자·바이너리와 원본 형상은 그대로였으며, 새 파일 해시에 묶인 눈 판정을 유지했다. 눈 안전 한계를 새 GLB에서 다시 계산한 결과 기존 값과 같았다. 체험 화면은 GLB 타깃 쌍을 확인한 뒤 탭을 열고, 다른 부위와의 동시 적용을 차단한다.

개발 서버의 실제 생성 GLB 3개를 승인된 비공개 임시 폴더에서 시험했다. 세 모델 모두 양방향 끝값의 접힘·과도한 늘어남·새 자기교차가 없고, 원본 정점·눈·코·입술·귀 보호 영역은 불변이었다. 정면 투영의 볼·턱선·목 폭과 측면 투영의 목 깊이는 각 방향과 일치했다(각 3/3). 이 결과는 세 얼굴에 한정되고 피부·머리카락·목 경계의 시각적 자연스러움이나 다른 편집과의 조합은 증명하지 않는다. 서버와 PC의 임시 원본·검사 결과 GLB는 시험 직후 삭제했다. 얼굴 자산이나 식별자는 이 문서에 기록하지 않는다.

생성 시안은 모델의 편집 지원 목록을 읽는 동안 눈·코·윤곽·체중 변화 탭을 선택할 수 있다. 모델 확인 전에는 슬라이더를 잠그고, 확인이 끝나면 지원되는 조절과 미지원 안내를 표시한다.

홈과 편집실의 체중 변화는 코·윤곽과 같은 조절 줄을 사용한다. 화면 값은 원본 0을 기준으로 부호가 있는 미리보기 강도를 표시하며, 접근성 값은 감량·증량 방향과 강도를 읽는다.

기존 모델에 체중 변화 타깃만 있는 경우에도 윤곽 후보를 생성할 수 있다(AI-736). 윤곽의 각 방향을 기존 형상 검사로 확인하고, 통과한 쌍만 새 GLB에 추가한다. 기존 체중 변화 타깃과 승인 판단에 쓰이는 메타데이터, 원본 GLB는 보존한다. 새 GLB의 해시로 관련 승인을 다시 검증한 뒤에만 같은 시안에 연결할 수 있다.
