# AI 실장님의 윤곽 조절

‘조금’과 정도를 생략한 문장은 작은 단계다. ‘보통’과 ‘많이’는 각각 중간·큰 단계로 해석한다. 한 문장에 부위가 여러 개 있으면 부위마다 정도를 읽는다. 화면은 시안의 조절 한계를 적용한 실제값을 표시한다.

서버는 현재 시안의 지원 코드와 범위를 확인한다. 여러 윤곽을 함께 조절한 결과에 두 개 이상의 윤곽 가중치가 남으면 해당 GLB에서 윤곽을 합성한 피부를 검사한다. 통과한 요청은 한 편집 이력으로 저장한다. 검사 실패 시 `EDIT_033`으로 안내한다.

GMS는 일상 표현의 후보를 반환한다. 서버는 원문 구절·효과·방향·강도·지원 코드를 확인한다. 직전 시안에 연결된 ‘둘 다’와 ‘더 줄여줘’는 서버에 저장된 대화·편집 이력과 대조한다.

선택한 부위에서 저장 없는 3D 비교를 시작하면, ‘그 부분만 살짝 좁혀서 보고 싶어요’처럼 부위명이 빠진 요청도 해석할 수 있다. GMS에는 직전 상담에 저장된 비교 항목을 전달한다. 서버는 그 항목과 요청 방향에 맞는 후보만 허용한다. 상담이나 시안이 바뀌면 이전 선택으로 비교하지 않는다.

눈·코·윤곽을 섞어 요청하면 명확한 조절 구절과 유지 구절을 먼저 나누어 해석한다. 정확히 해석한 요청은 GMS를 호출하지 않는다. 한 부위라도 방향을 확인할 수 없거나 해당 조절이 잠겨 있으면 전부 보류한다. 복합 편집은 실제 최종 피부를 검사하고 메시·리그·승인·편집값이 그대로일 때 한 이력으로 저장한다. 체중 조절 모드와 점 편집이 있는 시안의 복합 저장에는 별도 검사가 필요하다.

광대 타깃은 눈·코 보호 영역에서 변위가 0이고 경계 밖에서 부드럽게 원래 세기로 이어진다. 기존 개발 모델은 `infra/ec2/repair-cheekbone-dev.sh dry-run <시안 ID>`로 후보를 만들고, 같은 명령의 `apply`로 검사 후 연결한다. 전환은 이전에 GLB를 교체한 적 없는 모델에 한해 한 번 실행한다. 원본과 다른 타깃은 보존하고, 눈·코·체중 승인은 새 메시 해시에 맞춰 재결속한다. 기존 광대 값은 그대로 읽으며, 해당 모델에서 검증한 끝값을 다시 구웠기 때문에 동일 슬라이더 값의 광대 움직임은 줄 수 있다.

‘앞트임 10%, 광대 −10%로 맞춰줘’처럼 각 슬라이더의 표시값을 한 문장으로 지정할 수 있다. 같은 항목을 두 값으로 지정하거나 체중과 얼굴 조절을 함께 지정하면 전체를 보류한다. 눈을 포함한 얼굴 복합 검사에서 안구 보호 투영의 좌표 차이가 5×10⁻⁶ 이내면 허용하며, 보호 영역 변위·면 뒤집힘·새 자기교차는 계속 검사한다.
