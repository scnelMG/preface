# 상담 합성 보류셋 v2 (S15P31B204-304)

2026-11-04. 저장소·Jira·기존 예시를 보지 않은 별도 AI가 문장 24개를 작성했고, 다른 AI가 출시 범위만 보고 첫 라벨을 제안했다. 담당자가 [효과 계약](../../contracts/edit/effects-v1.md)과 [AI-299](https://ssafy.atlassian.net/browse/S15P31B204-299)의 지원 범위로 라벨을 교정하고 기존 [합성 코 문장](nose-consult-synthetic-v1.md), AI-76의 사전 고정 19·14문장, 테스트 표현과 중복을 대조해 **16개를 고정**했다. 이는 AI 제작 합성 문장이다. 독립 사용자 발화·2인 사람 라벨링·실제 GMS 결과가 아니다.

판정 조건: 얼굴 자료가 없는 비개인 합성 v2 모델에서 코 네 조절과 양쪽 트임 4종만 승인됐다고 가정한다. 기존 쌍꺼풀 주름이 있어 새 라인·높이 편집은 잠긴다. 같은 문장 전에 편집값은 0이고 후속 문맥은 없다. `+/-`는 화면의 코끝 위아래 그룹값이 아니라 **효과 코드의 방향**이다. 따라서 `nose.tip_height:-`는 아래로, `nose.tip_height:+`는 위로 이동이다. 정확한 %는 모델별 한계 때문에 기대값에 넣지 않는다. 코드·방향·좌우와 의도 기대값은 [기계 판정 CSV](consult-synthetic-holdout-v2-cases.csv)에만 둔다.
