# 상담 결과 제보와 회귀 처리 (S15P31B204-303)

2026-10-31 기준 상담창의 `상담 결과가 의도와 달라요` 링크는 팀 공용 문의 메일을 연다. 상담 원문·시안 ID·얼굴 자료는 링크에 넣지 않는다. 사용 경험 설문은 가입 이메일과 3D 만족도를 받는 별도 경로이므로 상담 오인식 제보로 분류하지 않는다.

## 접수와 삭제

1. 사용자가 메일을 직접 작성·발송한다. 안내 문구대로 얼굴 사진·GLB·실명·개인 측정값은 받지 않는다. 그 자료가 들어오면 평가셋이나 Jira에 옮기지 않는다.
2. AI 담당자가 팀 공용 문의 메일함에서 기대 변화와 실제 결과만 확인한다. 실제 문장을 평가셋에 재사용하려면 별도 동의와 삭제 경로를 먼저 확인한다. 동의 전에는 개발자가 새로 쓴 합성 문장으로만 재현한다.
3. 사용자가 삭제를 요청하면 같은 문의 연락처로 접수해 메일 원본과 별도 보관본의 삭제 여부를 담당자가 확인한다. Jira에는 개인 메일 주소·원문·시안/모델 ID·서명 URL을 넣지 않는다.

## 기록과 판정

제보마다 `F-번호`, 접수일, 분류, **합성** 재현 단계, 기대/실제 효과 코드·좌우·방향·질문 여부, 모델/리그/프롬프트/효과 계약의 비식별 버전, 담당 이슈, 수정 전후 회귀 결과, 해결/보류 상태를 기록한다. 얼굴 사진·원본 모델·실명·개인 측정값은 기록 필드가 아니다. 분류는 의도 해석, 용어, 후속 문맥, 모델별 미지원, 적용값·화면 불일치, 응답 지연 중 하나로 시작하고 원인이 확인되면 고친다. 긴급 오편집은 해당 유형을 무편집·되묻기로 제한한다.
