## 재현 기준

브라우저와 같은 원본 기준 합성으로 감량·증량 `contour.weight_shape_neg/pos`에 다른 한 효과를 더했다. 기본 모델의 코·윤곽은 GLB morph target, 생성 모델의 윤곽은 GLB morph target, 코는 해당 모델의 승인 리그와 `nose-engine`, 눈은 브라우저와 같은 2회 세분화·`eye-edit` 엔진으로 계산했다. 눈·코는 해당 단독 편집이 승인된 상태를 기준으로 체중 변화를 더했다. 검사 도구는 `services/gpu-worker/reconstruction/tools/audit_weight_combinations.py`와 같은 폴더의 눈·코 감사기다.

체중 방향 두 개, 상대 부위의 사용 가능 방향, **체중 강도 0.5·1과 부위 강도 0.5·1의 독립 조합**을 검사했다. 눈은 승인 한계의 0.5·1, 생성 코는 리그 한계의 0.5·1이다. 피부 삼각형 뒤집힘·붕괴·4배 이상 늘어남과 단독 부위 상태에 체중 변화를 더할 때 **새로 생긴 자기교차**를 검사했다. 눈은 세분화 피부에서 검사하고, 생성 코는 원본 GLB 피부와 리그의 `fit_sha` 결속을 확인했다. 단독 효과 자체에 있던 교차를 복합 효과의 새 결함으로 세지 않는다.

## AI-615 재검사와 기본 모델 수정

기본 모델에서 실패한 면은 두 입꼬리 부근에 모였다. 공개 합성 모델의 체중 모프만 입꼬리 중심 2~10 mm 구간에서 부드럽게 감쇠해 남녀 GLB를 다시 굽고, 중립 정점·기존 코·윤곽·눈 타깃·텍스처는 유지했다. 수정된 체중 타깃의 최대 차이는 약 0.05 mm다. 새 공개 자산은 남성 `c91c1d0d87cd4980ed0c93994688c7fa5ccff52f6c4f1829ffc673f9cfdc5b07`, 여성 `489123a432fbf8de8741ec26ab21faa72e9bcb06052c9ead21c55ecae2a96802` SHA-256에 결속한다. 두 파일의 눈 승인 한계는 재계산해 기존 값과 일치했다.

독립 슬라이더 검사값을 각 방향 `0.25·0.5·0.75·1`로 넓혔다. 이 격자에서 공개 기본 모델은 각각 704건, 개발 생성 모델 3종은 각각 윤곽 384건·코 리그 320건·눈 160건을 검사했다. 새 교차·접힘·과도한 늘어남은 0건이었다. 기본 모델 눈도 각 160건에서 새 결함 0건이었다. 공개 기본 모델의 체중 타깃은 감량·증량·원복을 브라우저 3D의 사선 시점에서 확인했다. 이 육안 확인은 다른 시점과 생성 얼굴의 피부 품질 판정을 대신하지 않는다.

세 효과 이상은 체중 양방향 끝값과 GLB 효과 두 개의 양방향 끝값을 더한 최종 피부를 검사한다. 생성 코는 GLB 모프가 아니라 별도 리그로 계산한다. 결함을 두 가지 기준으로 구분한다: 다른 효과만 적용한 상태에 체중을 더할 때 새로 생긴 결함, 원본에서 세 효과의 최종 메시까지 생긴 결함. 후자가 실제 동시 편집의 승인 기준이다. 눈은 세분화 피부에서 체중 추가 결함만 검사했으며, 원본 대비 최종 눈+체중 전수 검사는 600초 시간 제한을 넘겨 미완료다.

공개 남녀 기본 모델의 체중+GLB 효과 2개 조합은 각각 440건에서 체중을 마지막에 더할 때의 추가 실패는 0건이었지만, 원본 대비 최종 메시 실패는 남성 430건·여성 424건이었다. 남성 기본 모델의 단독 광대 모프만 원본에 적용해도 새 자기교차가 검출돼, 다수의 최종 실패는 체중 모프만의 문제가 아니다. 생성 모델 3종의 체중+윤곽 2개 조합은 각 120건에서 체중을 마지막에 더할 때의 추가 실패가 각각 0·3·0건이었지만, **원본 대비 최종 메시 실패는 98·116·80건**이었다. 세 모프 강도를 모두 25%로 낮춘 표본에서도 최종 메시 실패는 각각 68·110·36건이었다. 따라서 전체 부위에 공통으로 적용할 축소 범위도 산출할 수 없었다. 생성 수치는 비식별 표본 집계이며 나머지 모델에 일반화하지 않는다. 비공개 생성 GLB·코 리그는 검사 직후 로컬 임시 폴더와 서버 임시 위치에서 삭제했다.

복합 효과에 대해 **모든 값을 허용하는 연속 구간은 아직 승인하지 않는다.** 격자 표본이 통과해도 중간의 임의 값·세 효과 이상 조합·이전 단독 편집 결함까지 자동으로 안전해지는 것은 아니다. 후속 저장 경계는 현재 모델 GLB 해시, 코 리그 해시·버전, 눈 승인 해시·한계를 다시 결속하고 **요청한 실제 전체 가중치로 합성한 최종 메시**를 검사해야 한다. 불합격이면 무편집으로 거절하고 이력을 남기지 않는다. 화면은 같은 승인과 GLB 타깃을 확인한 뒤에만 조절을 보여 준다. 이 조건이 구현·검증되기 전까지 기존 체중 변화와 다른 부위의 동시 편집 잠금은 유지한다.

## AI-621 체중·윤곽 한 항목의 저장 경계

검사기 응답 버전은 `validatorVersion=1`이며 모델별 승인 JSON·GLB 해시에 결속한다.

`/internal/ai/v1/composite`는 현재 GLB SHA-256과 fit 결속, 체중·윤곽 타깃 쌍, 보호 영역을 확인한 뒤 요청한 **정확한 두 가중치**로 최종 피부를 합성한다. 윤곽만 남기는 전환도 안전하도록 같은 윤곽 가중치의 단독 최종 메시를 먼저 확인한다. 원본 대비 면 접힘·과도한 늘어남·새 자기교차가 있으면 불합격이다. 윤곽 단독과 최종 합성 모두 눈·코 보호 영역의 허용 이동량을 넘으면 거절한다. 검사 요청은 시안 행 잠금 밖에서 진행하고, 저장 거래는 모델·시안 행을 잠가 시안 버전·모델 자산 키·승인 JSON·전체 가중치가 검사 당시와 같은지 다시 확인한다. 검사기 장애·해시 불일치·불합격은 이력 없이 거절한다. undo/redo로 같은 복합 상태에 돌아갈 때도 다시 검사한다. 코·눈·제어점 또는 윤곽 두 항목 이상과의 조합은 계속 잠근다.

개발의 승인된 생성 GLB 3개를 임시로 읽어 검사했다. 한 모델에만 윤곽 타깃 쌍이 있었다. 그 모델에서 체중 양방향과 윤곽 여섯 항목의 양방향을 조합하고 두 강도를 같은 수준(0.25 또는 1)으로 설정한 48개 표본 중 22개가 통과했다. 다른 두 모델은 윤곽 타깃이 없어 미지원이다. GLB 해시는 서버 승인값과 대조했고 로컬·서버 임시 파일은 삭제했다. 이 집계는 특정 얼굴이나 다른 연속 강도의 안전성을 입증하지 않는다. AI-621 단독 개발 배포 시점에는 사용자 화면·채팅의 동시 편집 잠금을 유지했다. 개발 API의 실제 저장·재조회 시험은 AI-625와 함께 진행한다.

## AI-625 생성 시안의 화면과 채팅

AI-625에서는 체중과 윤곽 타깃이 함께 확인된 생성 시안에서 윤곽 한 항목과 체중을 함께 조절했다. 슬라이더를 놓으면 최종 형상 검사를 요청했고, 채팅 후보도 같은 검사를 거쳐 한 이력으로 저장했다. 기본 모델의 동시 편집은 별도 최종 형상 검증이 필요하다.

이력 복원이나 채팅 응답을 기다리는 동안 새 슬라이더 입력을 잠근다. 시안을 옮긴 뒤 도착한 이전 시안의 응답은 현재 3D에 반영하지 않는다.

## AI-631 눈·코·윤곽·체중의 저장 검사

체중과 윤곽 한 항목의 기존 판정은 검사기 버전 1을 사용한다. 눈·코 또는 여러 윤곽이 함께 적용되면 버전 2가 요청한 전체 가중치와 눈 상태를 검사한다. 코 리그를 원본 피부에 적용하고, 눈 변형이 있는 경우 세분화 정점으로 코와 GLB 모프의 변위를 옮겨 합산한다. 합산한 피부에서 접힘·교차·안구 침범과 보호 영역을 확인한다. 분리된 피부끼리의 교차를 검사할 수 없는 눈 복합 모델은 보류한다.

서버는 검사한 시안 버전, 전체 가중치와 눈 상태, 메시·리그 자산 및 승인이 저장할 값과 같은지 확인한다. 슬라이더 저장과 이력 복원이 같은 판정을 사용한다. 적용 가능 여부는 모델과 요청값마다 다르며, 개발 시안의 네 효과 저장·재조회 QA는 화면 연결 후 진행한다.

## 복합 편집의 실시간 미리보기

생성 시안은 드래그하는 동안 임시 조절값을 3D에 표시한다. 손을 떼면 최종 형상 검사와 저장을 한 번 요청한다. 검사에 실패하면 임시 표시를 걷고 직전에 저장된 슬라이더 값과 3D를 보여 준다. 검사를 통과한 상태가 저장 및 이력에 반영된다.

## AI-642 편집 모드 분리

새 편집은 눈·코·윤곽 모드와 체중 변화 모드 중 하나에만 저장한다. 전환으로 원본이 되는 항목을 먼저 안내하고, 전환 버튼을 누른 경우에 한 단계로 저장한다. 이미 저장된 복합 시안은 열람할 수 있고, 기존 복합 이력은 같은 형상 검사를 거쳐 복원한다. 직접 조절은 드래그 중 즉시 3D에 반영하고 손을 뗄 때만 저장한다. 일반 저장 중 새 조절값은 계속 미리 보며, 서버 요청은 시안 버전 순서로 보낸다.

## 체중 변화의 현실성 경계

이 형상 검사는 **실제 체중 변화에 따른 얼굴 예측 정확도**를 판정하지 않는다. 현행 모프는 볼살·교근·목의 공학적 변위다. [De Greef 외](https://pubmed.ncbi.nlm.nih.gov/16563680/)는 성인 967명의 BMI·연령·성별과 얼굴 연조직 두께의 단면 관계를 측정했고, [Zhao 외](https://pubmed.ncbi.nlm.nih.gov/29535075/)는 그 회귀를 특징점 이동과 라플라시안 변형에 사용해 2D 초상화의 체중 방향 모습을 만들었다. 두 연구도 이 프로젝트의 생성 3D 모델이나 개인별 kg-얼굴 대응을 검증하지 않는다. Zhao 논문은 큰 변형에서 목 주변 인공 흔적을 보고한다. [동일인 전후 자료·독립 검증 조건](weight-kg-calibration-feasibility.md)이 충족되기 전에는 kg 단위·목표 체중 얼굴 표시를 추가하지 않는다.
