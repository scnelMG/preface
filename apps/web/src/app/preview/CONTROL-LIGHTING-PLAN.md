# 조작 카드·조명 개선 계획

2026-10-29 사용자 검토 요청에 대한 계획이다. 이 문서의 카드 구조 변경은 아직 적용하지 않았다.

## 현재 문제

조명 설정은 편집 카드의 첫 자식으로 추가된다. 열면 카드 콘텐츠 높이와 정렬이 달라지고 부위 탭·슬라이더·비교 버튼이 밀린다. 장면 바깥의 별도 조명 버튼과 카드의 관계도 약하다. 현재 조명 아이콘을 활성 상태에서도 보이게 하는 보완만 적용했다. 브라우저 측정에서 조명 열림 후 비교 버튼이 약 193px 아래로 이동했다. 이 이동을 없애는 것이 우선이다.

## 참고와 적용 범위

- [Spline 인터페이스 문서](https://docs.spline.design/basics/understanding-splines-ui): 3D 작업 영역과 고정된 속성 인스펙터의 역할 분리, 조명과 재질의 속성 묶음을 참고한다. 복잡한 X/Y/Z 값은 Preface에 가져오지 않는다.
- [visionOS](https://www.apple.com/os/visionos/): 공간 콘텐츠와 조작 패널의 위계를 참고한다. 큰 장식 효과 대신 선택 상태와 실제 조작 결과로 반응을 보여준다.
- 이 서비스에서는 얼굴 편집이 주 작업이고 조명은 관찰을 보조한다. 조명 때문에 얼굴 편집 카드의 기준선을 옮기지 않는다.

## 제안 구조

1. 카드 상단에 `코 · 눈 · 헤어`와 우측의 작은 조명 아이콘을 같은 기준선으로 정렬한다. 활성 아이콘만 보라색으로 채운다.
2. PC·태블릿의 조명은 카드 옆 독립 팝오버로 연다. 편집 카드의 너비·상단·비교 버튼 위치를 바꾸지 않는다. 화면 안쪽에 들어오도록 배치한다.
3. 모바일은 조명만 하단 시트로 연다. 닫으면 사용하던 부위·슬라이더·모델 시점을 유지한다.
4. 조명 내용은 위치를 직접 옮기는 작은 패드와 밝기 슬라이더만 유지한다. 각도 숫자·기본/측면/상단 버튼을 추가하지 않는다. 초기화는 작은 보조 동작으로 둔다.
5. 카드 반경·간격·아이콘 크기·상태 색을 공통 토큰으로 묶는다. 본문이나 버튼마다 보라색을 넓게 쓰지 않는다.

## 확인할 기준

- 조명 열기 전후 편집 카드와 비교 버튼의 좌표가 같다.
- 조명 패널이 화면 밖으로 나가지 않고 모델 조작·부위 선택과 충돌하지 않는다.
- Escape로 닫으면 조명 버튼에 초점을 돌린다. 모바일 시트는 닫힌 뒤 원래 스크롤 위치를 유지한다.
- 320·768·1280px와 모션 감소 설정에서 확인한다.
- 전후 비교는 조명 패널과 무관하게 같은 카메라·같은 배율을 유지한다.

## 후속 결정 · 2026-10-29

사용자 요청으로 팝오버·시트 계획 대신 더 작은 직접 조작을 적용했다. 밝기는 기본값으로 고정하고 장면 도구 위치에 52px 원형 위치 패드를 둔다. 구 위의 점을 드래그하거나 방향키로 움직여 빛의 방향만 바꾼다. 패널을 여닫지 않아 편집 카드의 좌표·높이가 바뀌지 않는다. 위 제안 구조는 이전 대안으로 남긴다.
