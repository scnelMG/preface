# Preface 로컬 시안의 디자인

`/preview` 하위 화면의 기준이다. 시안 자체는 실제 계정·촬영·저장 API를 사용하지 않는다.

## 방향과 레퍼런스

사용자가 선호한 좌측 소개·중앙 모델·우측 도구의 메인 배치와 작업실의 큰 모델 선택 구성을 유지한다. 조명·장식 효과만으로 새로운 디자인을 만들었다고 설명하지 않는다. 모델을 다루는 공간과 선택 도구의 크기·간격·재질을 정돈한다.

- [Daydream Player](https://www.daydreamplayer.com/): 실제 페이지의 제품 중심 구성, 작은 정사각 앨범 커버, 절제된 물리적 조작부를 참고한다. 빨간 배경과 제품 자산은 복제하지 않는다.
- [Awwwards A24](https://www.awwwards.com/inspiration/desktop-a24): 크게 보여주는 대상과 작은 선택 도구의 위계를 참고한다.
- [baseline-ui](https://github.com/ibelick/ui-skills/tree/main/skills/baseline-ui): 위계·여백·색상 절제와 접근 가능한 조작 기준을 적용한다.

## 화면과 조작

공통 토큰과 편집 도구는 `preview.css`, 랜딩·촬영은 `flow.css`, 작업실은 `workspace/workspace.css`가 담당한다. 글꼴은 로고까지 Pretendard 한 가족을 공통 사용하고 소셜 로그인 버튼도 같은 글자 규칙을 적용한다. 보라는 로고와 키보드 초점 위주로만 쓴다.

작업실의 선택부는 작은 점과 활성 선으로 표시한다. 커버 갤러리는 사용하지 않는다. 이름과 생성 날짜는 중앙 모델 아래에 함께 놓고, 시안 수는 한 번만 표시한다. 아래에는 시안 카드와 저장 날짜를 제공한다. 모델이 많으면 현재 선택 주변의 위치 표시 최대 일곱 개를 유지한다.

중앙 모델은 메인·작업실·편집실 모두 `FaceViewer`를 사용한다. 작업실 선택 화면은 회전만 허용하며 우클릭 이동과 휠 확대를 끈다. 메인과 편집실은 기존 회전·이동·확대를 유지한다. 양옆 모델은 작고 낮은 채도·불투명도로 두어 선택한 모델과 위계를 만든다.

메인의 제목과 설명은 로그인 여부에 관계없이 같고, '촬영한 내 얼굴을 3D로.'를 한 색으로 쓴다(2026-10-30, 보라는 바뀐 값 표시에만 쓴다). 활성 아이콘은 보라색 채움으로 표시한다. 넓은 보라 배경은 추가하지 않는다.

확대 캔버스의 실제 크기를 장면 전체에 맞추고, 그 범위의 상단·양측 외곽에서만 알파를 부드럽게 줄인다. 얼굴 위에 색상 띠를 얹지 않고 하단 페이드는 사용하지 않는다. 비교는 `comparisonOverflow`로 내부 반쪽 scissor 없이 같은 배율로 두 모델을 투영한다. 실제 FaceStage도 같은 프레이밍과 비교 겹침 제한을 사용한다.

조작 카드와 조명의 다음 구조는 [별도 계획](CONTROL-LIGHTING-PLAN.md)에 정리했다. 카드 안에 조명을 삽입해 기존 조절 요소를 밀어내는 구조를 독립 팝오버와 모바일 시트로 바꾸는 안이다. 이후 사용자 피드백에 따라 밝기는 고정하고 모델 아래의 구형 선 아이콘과 점으로 위치만 조절하는 구조를 적용했다. 이전 팝오버 계획은 현행 구현이 아니다.

반응형 화면은 모바일에서 소개·모델·도구 순서로 쌓고 네비게이션 기능·순서를 유지한다. 키보드 초점은 모델 외곽선 대신 커버 하단 표시로 구분한다. 모션 감소 설정을 따르고 화면 밖·비활성 탭의 촬영 안내 애니메이션은 멈춘다.

## 촬영과 샘플 데이터

촬영 연결은 실제 인증을 바꾸지 않는 로그인 이후 상태의 로컬 시안이다. PC에는 QR, 모바일에는 현재 휴대폰에서 안내를 보는 액션을 제공한다. 실제 연결·카메라 촬영은 서버 복구 후 사용할 수 있다고 명시한다.

안내 순서는 왼쪽·정면·오른쪽·정면·위·아래다. 얼굴은 고정하고 카메라가 이동한다. 첫 정면에서 4.4초간 멈춰 반대 손으로 바꿔 잡도록 안내한다. 좌우 기준 설명은 화면에 쓰지 않는다. 일시정지·직접 선택을 제공한다.

모델·시안·날짜는 검토용 샘플이며 실제 계정 이력이 아니다. 실제 얼굴 사진과 자격 증명을 추가하지 않는다. 로딩 배경은 베이지·크림색 없이 중립색으로 유지한다.

## 변경 이력

- 2026-10-29: 로컬 메인·작업실·편집실·촬영 연결 시안을 만들고 디자인 기준을 정리했다.
- 2026-10-29: 사용자 피드백에 따라 작은 무기명 앨범 커버와 공통 뷰어로 수정했다. 넓은 그라데이션을 제거하고 비교 내부 절단선을 렌더링에서 해결했다.

- 2026-10-29: 갤러리를 선·점 위치 표시로 교체하고 모델 생성 날짜를 이름 옆으로 옮겼다. 선택 화면은 회전만 허용하고 로그인·비로그인 메인 문구를 통일했다. 로컬에 남아 있는 GLB 두 개를 개발 전용·루프백 경로로 연결했다. 얼굴 파일·실제 사진은 저장소에 복사하지 않는다. 로컬 모델 날짜는 GLB 생성 메타데이터를 사용한다.

### 2026-10-29 추가 검토 반영

- 프로필은 원형 배경을 유지한다. 작업실만 활성 보라색 채움으로, 알림·서비스 열림은 검정 선 아이콘으로 구분한다.
- 메인은 얼굴 생성·형태 편집·전후 비교를 설명하고 제목은 ‘촬영한 내 얼굴을 / 3D로.’ 두 줄로 쓴다. ‘3D’만 강조한다. 같은 내용을 반복하는 보조 설명은 생략하고 문구 하나만 제공한다. 강조색은 #7042e8이다.
- 조명은 밝기를 고정하고 카드 외부의 작은 구형 위치 패드에서 점만 움직인다. 별도 패널이 없어 카드 정렬이 변하지 않는다.
- 작업실 중앙은 정면, 양옆은 측면으로 시작한다. 화살표·모델·검정 위치 바 클릭으로 선택하며 호버는 선택을 바꾸지 않는다.
- 선택됨 배지와 샘플·로컬 모델 개수 문구는 화면에서 제거한다.
- 시안의 전후 비교 확대는 현재 시점의 모델 수평 경계가 각각의 슬롯 안에 남는 최소 거리로 제한한다.

### 조명과 장면 하단 정렬 · 2026-10-29

- Fab 3D 뷰어의 장면 도구를 모으는 구조를 참고한다. https://dev.epicgames.com/documentation/fab/using-the-3d-editor-in-fab
- model-viewer의 조명과 배경을 분리하는 접근을 참고한다. https://modelviewer.dev/examples/lightingandenv/
- 음영 구 대신 얇은 원·경선과 검정 점으로 조명 방향만 표시한다. 밝기는 기본값을 유지한다.
- 모델명·조명 조작을 같은 줄, 마우스 안내를 바로 아래 줄에 둔다. 메인과 편집실에서 같은 하단 묶음을 사용한다. 편집 카드는 이동시키지 않는다.

- 2026-10-30: 실제 서비스 연결 검토 문서를 연결하고 현행 제목·비교·조명 구조를 기록했다.

### 메인 리디자인 1차와 글꼴 · 2026-10-30

- 레퍼런스: Awwwards 수상작(Lusion, Igloo Inc, KOBA skincare 등)과 Spline·Linear에서 구조와 리듬만 참고했다. 브랜드 자산은 쓰지 않는다.
- 메인 슬라이더는 편집실과 같은 `noseControls`·`SliderRow`를 쓴다. 콧대 / 코끝(돌출·내림) / 콧볼 4개, 값은 모델별 범위의 −100~100%다.
- 바뀐 값만 모델 옆 보라 세로선에 이름과 %로 적는다. 보라는 이 "바뀐 값"과 슬라이더에만 쓰고, 제목 강조는 뺐다.
- 조절 패널은 그림자 카드 대신 얇은 선의 반투명 면으로 둔다. 3D가 뜨기 전에는 같은 뷰어로 렌더한 정면 WebP를 먼저 보여 준다.
- 글꼴은 로고까지 Pretendard 한 가족(npm `pretendard` 1.3.9, OFL-1.1)으로 바꿨다. 영문 DM Sans와 한글 Noto Sans KR이 한 줄 안에서 높이·굵기가 어긋나던 문제를 없앤다. 화면에 필요한 unicode-range 조각만 받는다.
